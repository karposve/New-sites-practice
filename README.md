# Архивный след

Черновик сайта услуги по поиску предков в архивах бывшего СССР. Учебный проект.

- `site/v3.html` — актуальная версия (листающаяся метрическая книга на первом экране)
- `site/v2.html`, `site/index.html` — более ранние версии
- `brand/` — шрифты, логотипы и цвета, общие для всех версий

Цены, сроки и контакты на страницах — заглушки. Форма заявки демонстрационная и никуда не отправляет данные.

Шрифты Oswald, PT Sans и Bad Script — лицензия SIL OFL 1.1 (тексты лицензий в `brand/fonts/`). Источник герба — в `site/img/SOURCES.md`.
